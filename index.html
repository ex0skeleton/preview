About Preview Wiz

Preview your design files in your browser. Your files stay on your device.

How to use

Drag and drop files or choose them. Select a file in Workspace. Use the zoom buttons or mouse wheel, then drag the artwork to pan. Fit returns it to the window.

Illustrator artboards

Choose Artboards to see one page at a time, or View all for an overview of the PDF pages available inside the file. The overview arranges them in a grid; it is not the Illustrator canvas layout.

Artwork outside artboards is usually not included in the PDF preview. This viewer cannot reliably recover or display it. Open the file in Illustrator or ask the designer to put that artwork on an artboard.

Supported files and limits

AI files need “Create PDF Compatible File” enabled. PSD viewing uses the saved composite; save with “Maximize Compatibility” in Photoshop. PDF, SVG, PNG, JPG, WebP, GIF, AVIF, BMP, ICO, HEIC/HEIF and TIFF are also supported. TIFF shows the first page. CDR and EPS show an embedded preview when available; these previews can be low resolution and may be missing or outdated. Complex artwork, colors and fonts can differ from the original application. Large files may need more memory. PDF/AI pages render at the available screen and zoom resolution. If the device cannot render at the requested quality, a reduced-quality warning appears.

Diagnostics

Export a log if you need help. It records technical events and file types and sizes, but excludes artwork contents and file names.
